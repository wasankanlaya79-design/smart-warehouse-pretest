# Smart Warehouse · แบบทดสอบก่อนอบรม

เว็บภาษาไทย 20 ข้อ มีลงทะเบียน ตรวจคำตอบครบ ตรวจคะแนนฝั่ง Google Apps Script และบันทึกลง Google Sheets ส่วนตัว คะแนนไม่มีเกณฑ์ผ่าน–ไม่ผ่าน

## สถานะเนื้อหา

คำถามเวอร์ชัน `smart-wh-slides-draft-v1` เป็น **ร่างใหม่จากข้อความที่อ่านได้ในสไลด์ Smart-WH_Module 3-4.pptx** ไม่ใช่คำถามเดิมที่กู้จากแชต: แชตอ้างอิงแสดงคำตอบเป็น content-reference ซึ่งยังอ่านเนื้อหาไม่ได้ สไลด์หลายหน้าเป็นรูปภาพ จึงไม่อ้างว่าได้ถอดข้อความจากภาพครบทุกหน้า ต้องตรวจเทียบคำถามเดิมก่อนเปิดใช้อบรมจริง

ดู `QUESTIONS.md` สำหรับคำถาม ตัวเลือก เฉลย และเลขหน้าสไลด์ที่อ้างอิง ไม่อัปโหลดสไลด์ต้นฉบับหรือข้อมูลผู้เข้าอบรมลง repo สาธารณะ

## โครงสร้าง

- `index.html`, `styles.css`, `app.js`: หน้าเว็บบน GitHub Pages
- `questions.js`: คำถามและตัวเลือกสำหรับผู้เข้าอบรม
- `config.js`: URL Web App, เวอร์ชัน และสวิตช์เปิดรับคำตอบ
- `apps-script/Code.gs`: ตรวจข้อมูล ตรวจคะแนน ป้องกันรายการซ้ำ และสร้างใบยืนยัน
- `apps-script/appsscript.json`: manifest สำหรับ Apps Script
- `privacy.html`: ข้อมูลที่เก็บและวิธีติดต่อผู้จัด

## ตั้งค่า Google Apps Script

1. สร้าง standalone Apps Script และวาง `Code.gs` ในไฟล์สคริปต์
2. ตั้งเขตเวลา Asia/Bangkok หรือใช้ manifest ที่ให้มา
3. เลือกฟังก์ชัน `setup` แล้วเรียกใช้ เจ้าของบัญชีต้องตรวจและอนุญาตสิทธิ์ Google Sheets ด้วยตนเอง สคริปต์ต้องใช้สิทธิ์ spreadsheets เพื่อสร้างและเปิดชีต ไม่ขอ Gmail หรือสิทธิ์อ่านไฟล์ Drive ทั่วไป
4. `setup` สร้างชีตส่วนตัวและบันทึก ID ใน Script Properties ชื่อ `SPREADSHEET_ID` เรียกซ้ำจะไม่สร้างชีตใหม่ ดูลิงก์ชีตใน Execution log เก็บชีตเป็นส่วนตัว
5. Deploy → New deployment → Web app → Execute as Me → Who has access: Anyone (เพื่อให้ผู้เข้าอบรมส่งได้โดยไม่ลงชื่อเข้าใช้)
6. นำ URL ที่ลงท้าย `/exec` ใส่ `config.js` และตั้ง `ready:true` **หลังตรวจการรับส่งและบันทึกสำเร็จแล้ว**
7. เมื่อแก้ Code.gs ให้เผยแพร่เวอร์ชันใหม่ผ่าน Manage deployments ด้วย โค้ดใน GitHub และ Apps Script ไม่ซิงก์กันอัตโนมัติ

ระบบไม่ใช้ fetch แบบ no-cors: เบราว์เซอร์ส่งฟอร์ม POST ไปยัง Apps Script แล้วแสดงผลตรวจคะแนนจากเซิร์ฟเวอร์ หลัง `SpreadsheetApp.flush()` สำเร็จเท่านั้น ข้อมูลลงทะเบียนจะถูกบันทึกพร้อมคำตอบเมื่อกดส่ง การเริ่มทำแบบทดสอบยังไม่สร้างแถวในชีต

## GitHub Pages

Settings → Pages → Deploy from a branch → main → /(root) → Save ไม่ต้องติดตั้งแพ็กเกจหรือสร้าง build

## การตรวจสอบก่อนเปิดจริง

- ตรวจและยืนยันคำถามกับผู้สอน รวมถึงแก้ `sourceNote` เมื่อเทียบคำถามเดิมแล้ว
- ตรวจการลงทะเบียน การตอบไม่ครบ และจอมือถือ
- ส่งข้อมูลทดสอบที่ระบุชัดว่า TEST; ตรวจว่าคะแนนตรงเฉลยและมีแถวจริงใน Responses
- ส่ง payload เดิมอีกครั้งต้องไม่เพิ่มแถว; เปลี่ยนคำตอบแต่ใช้ attemptId เดิมต้องถูกปฏิเสธ
- เปิด `/exec` แบบไม่ลงชื่อเข้าใช้ ต้องแสดงความพร้อม และต้องไม่เปิดเผยชีตหรือข้อมูลผู้เรียน
- ผู้จัดกำหนดระยะเวลาเก็บข้อมูล ช่องทางติดต่อ และผู้มีสิทธิ์อ่านชีตก่อนรับผู้เรียนจริง

## ขอบเขต

นี่คือ pretest สาธารณะ ไม่ใช่ระบบสอบที่ยืนยันตัวบุคคล: ไม่มีระบบล็อกอินหรือจำกัดหนึ่งครั้งต่อบุคคล ผู้ใช้เริ่มใหม่ได้ โค้ดเฉลยใน repo เป็นสาธารณะ Endpoint สาธารณะอาจรับข้อมูลรบกวนหรือถึงโควตา Apps Script ได้ การตรวจข้อมูลและล็อกป้องกันแถวซ้ำไม่ใช่การป้องกันบอต

ชื่อ หน่วยงาน และคำตอบเก็บชั่วคราวใน sessionStorage ของแท็บ เพื่อส่งใหม่เมื่อเครือข่ายขัดข้อง ระบบไม่แสดงว่าบันทึกสำเร็จจากการกดส่งอย่างเดียว หากหน้า Google ขัดข้อง ให้ย้อนกลับแล้วส่งข้อมูลเดิม เลขอ้างอิงเดิมจะป้องกันการเพิ่มแถวซ้ำ
